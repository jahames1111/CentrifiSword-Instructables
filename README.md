# Centrifisword
<img width="256" height="624" alt="Screenshot 2026-10-14 182025" src="https://github.com/user-attachments/assets/bb439f02-a033-40b3-afb7-5ab72cf9f6d7" />

A repo for my fully extendable 32-inch nylon sword that slides into the handle when not being used. Meant for a Halloween costume. Exhaustively designed in Tinkercad.

Tinkercad link: [Tinkercad](https://www.tinkercad.com/things/4jkv4komEuA-centrifisword)

Has decorative, illuminated lights around the hilt to give it a cool red glow, powered by one CR2032 battery.


Has 4 ~8-inch segments that will slide out and lock into each other when you flick it out. When not out, everything is contained in the hilt.

Features 4 RED LEDS in the hilt to light up the blade.
